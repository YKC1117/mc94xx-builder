完整編碼對照

這裡是給需要了解料號結構的人看的。不是所有理論組合都一定有現貨或可訂購 SKU，因此正式下單仍需業務確認。

正確看法：MC9400 與 MC9450 的前綴不同。A6 常見公開 SKU 中，MC9400 為 MC9401-0G1…，MC9450 則可見 MC945B-3G1…，後面再接掃描、記憶體、鍵盤、環境、電池與區域碼。

1｜通訊與系列

系列 / 前綴通訊能力適用情境
MC9401-0G1Wi‑Fi 6E / Bluetooth已有完整 Wi‑Fi 覆蓋的倉庫、工廠、室內作業。
MC945B-3G1Wi‑Fi 6E + 5G WWAN戶外、跨區、港口、堆場、私有 5G；MC9450 另支援 nano SIM、eSIM、GNSS。

2｜掃描模組

代碼模組用途
JSE4770標準距離 1D / 2D 掃描，一般揀貨與進出貨。
MSE58 IntelliFocus遠近兼具的長距掃描，官方標示可到超過 30.5 公尺。
PSE4770 + 前後相機標準掃描，加上拍照、品檢、貨損記錄等影像需求。
RSE58 + 前後相機長距掃描，同時需要影像功能。
